# HangarX Legal & Support

Static GitHub Pages website for HangarX.

## Pages
- `index.html`
- `privacy.html`
- `terms.html`
- `support.html`
- `contact.html`

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your `hangarx-legal` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

Your site should then be available at:

`https://YOUR_GITHUB_USERNAME.github.io/hangarx-legal/`

Useful App Store URLs:
- Privacy Policy: `https://YOUR_GITHUB_USERNAME.github.io/hangarx-legal/privacy.html`
- Support: `https://YOUR_GITHUB_USERNAME.github.io/hangarx-legal/support.html`
- Terms: `https://YOUR_GITHUB_USERNAME.github.io/hangarx-legal/terms.html`

Before release, ensure the policy text matches the final app behavior and App Store privacy disclosures.
